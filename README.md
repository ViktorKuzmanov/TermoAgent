# TermoAgent · Енерго Систем

Веб-апликација за машинските инженери на Енерго Систем: **пресметка на топлинско оптоварување по EN 12831-1**,
**избор на топлинска пумпа** (MDV, Mitsubishi Electric, Vaillant) и **генерирање понуда** за клиентот (Word .docx и PDF).

## Стартување

Потребно: [Node.js](https://nodejs.org) 18 или понова верзија.

```bash
git clone https://github.com/ViktorKuzmanov/TermoAgent.git
cd TermoAgent
npm install
npm run dev
```

Потоа отворете **http://localhost:5173** во прелистувач.

Други команди:

```bash
npm test           # тестови на пресметковниот модул
npm run build      # продукциски build во dist/ (статички фајлови, може на кој било хостинг)
npm run preview    # преглед на продукцискиот build
```

## Тек на работа (5 чекори)

1. **Клиент и локација**: клиент, адреса, град → θe, θm,e, HDD.
2. **Објект**
   - *Брз режим*: површина, катност, форма, застаклување, изолација (5 нивоа), под/покрив → обвивката се генерира автоматски.
   - *Детален режим*: простории со елементи (ѕид/прозор/врата/покрив/под; кон надвор / негреано (b_u) / тло / соседен простор).
   - Херметичност n50, заштита од ветер, рекуперација, ΔU_TB, загревање по прекин.
3. **Топлинско оптоварување**: Φ_T, Φ_V, Φ_RH, Φ_HL, W/m², загуби по елементи и по простории.
4. **Топлинска пумпа**: грејни тела и температура на напојување, ТСВ, фази. Најмалиот модел по бренд што покрива ≥ X % при θe, бивалентна точка, потребен греач, дијаграм капацитет/оптоварување.
5. **Понуда**: ставки (автоматски од избраниот модел, сите уредливи), попуст, ДДВ 18 %, споредба на трошоци (струја/нафта/пелети/дрва), прилог со детална пресметка. Излез: **Word (.docx)** и **Печати / PDF**.

Проектите и поставките се чуваат локално во прелистувачот (localStorage). Проектите и каталогот може да се извезат и увезат како JSON.

## Пресметка (src/domain/en12831.ts)

- Φ_T = Σ A·U_eff·(θint − θe). За надворешни елементи U_eff = U + ΔU_TB, за негреани простори се множи со b_u, за соседен простор f = (θint − θadj)/(θint − θe).
- Под на тло: U_equiv по EN ISO 13370 (B' = A_g / 0.5P, λ = 2.0 W/mK), f_g1 = 1.45, f_g2 = (θint − θm,e)/(θint − θe), G_w.
- Φ_V = 0.34·V̇·ΔT, V̇ = max(V̇_inf, n_min·V), V̇_inf = 2·V·n50·e·ε. Со рекуперација: V̇_inf + n_min·V·(1 − η).
- Пумпа: линеарна интерполација на капацитет (A7/A2/A−7/A−15 при W35), корекција −0.7 %/K над W35, бивалентна точка со бисекција.

## ⚠️ Да се провери пред предавање на клиентот

- **Каталог** (Поставки → Каталог): капацитетите/COP/SCOP се *типични вредности за серијата*, не официјални. Енерго Систем треба да ги потврди од техничките листови и да ги внесе **цените**. Шифрите на MDV и Mitsubishi хидробоксовите се од нивниот веб-сајт. Vaillant aroTHERM plus е претпоставен модел, бидејќи Vaillant пумпи не се наведени на сајтот.
- **Климатски податоци** (Поставки → Климатски податоци): θe / θm,e / HDD се ориентациски. Треба да се усогласат со македонскиот правилник / национален прилог.
- **Податоци за фирмата**: ЕДБ, жиро сметка, лого (Поставки → Фирма).
- Цените на енергенти за споредбата на трошоци.
